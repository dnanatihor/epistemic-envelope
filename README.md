# Epistemic Envelope — Separate certified, observed, and AI-inferred claims in API responses

[![CI](https://github.com/ovaledge/epistemic-envelope/actions/workflows/ci.yml/badge.svg)](https://github.com/ovaledge/epistemic-envelope/actions/workflows/ci.yml)

> **Status:** under construction. The build plan is in [SPEC.md](SPEC.md). The normative standard is [spec/SPEC-ENVELOPE.md](spec/SPEC-ENVELOPE.md).

## Why

AI-facing data APIs return results of approved data-quality rules, statistics from automated profiling, and content generated by models in one response. Agents and people reading that response cannot tell which claims are authoritative, so a model consuming it treats every statement as equally true.
